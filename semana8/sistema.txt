¿Qué información muestra cada comando?
-Comando: uname -a
Muestra información completa del sistema operativo, incluyendo el nombre del sistema, la versión del kernel, la arquitectura del procesador y otros detalles técnicos.
-Comando: whoami
Muestra el nombre del usuario que está utilizando la sesión actual del sistema.

¿Por qué es útil conocer esta información cuando se administra un servidor?
Conocer la información del sistema permite identificar el entorno donde se trabaja, verificar la versión del sistema operativo, comprobar la arquitectura del equipo y saber con qué usuario se están ejecutando las tareas. Esto ayuda a realizar configuraciones correctas, solucionar problemas, mejorar la seguridad y administrar el servidor de forma eficiente.

La ruta POST http://localhost:3000/registro recibe los datos enviados en formato JSON.
Cuando se envía:

{
  "nombre": "Maria",
  "mensaje": "Hola comunidad"
}

el servidor responde con:

{
  "estado": "Datos recibidos",
  "nombre": "Maria",
  "mensaje": "Hola comunidad"
}

Esto indica que el servidor recibió correctamente la información enviada y la devuelve junto con un mensaje de confirmación en el campo "estado".
